# HS80 RGB v1.0.0

Primeira versão estável do HS80 RGB para Windows 11. Controle a iluminação lateral do Corsair HS80 RGB USB com fio (`1B1C:0A88`) sem instalar o iCUE.

Atualização da release: o ícone Corsair foi ampliado e agora é embutido no iniciador, que também fornece o ícone ao atalho do Windows. Execute `-InstallStartup` novamente após atualizar para renovar o item em Aplicativos de inicialização.

## Recursos

- Apaga os LEDs ou aplica uma cor estática com brilho configurável.
- Inclui seis animações: `Rainbow`, `Breathe`, `Cycle`, `Blink`, `Heartbeat` e `Random`.
- Permite iniciar com o Windows sem janela de console.
- Exibe **HS80 RGB - Ricardo Braga Lab** em Aplicativos de inicialização e embute o ícone da Corsair no iniciador.
- `-UninstallStartup` remove o atalho e os arquivos instalados sem enviar comandos ao headset nem encerrar uma animação ativa.

## Download

Baixe `hs80-rgb-v1.0.0.zip` em **Assets** e extraia todo o conteúdo. Execute `hs80-rgb.bat` pelo PowerShell na pasta extraída. Não é necessário instalar Git, Python, iCUE ou bibliotecas externas.

```powershell
# Conferir a versão
.\hs80-rgb.bat -Version

# Apagar os LEDs
.\hs80-rgb.bat

# Aplicar roxo a 30% de brilho
.\hs80-rgb.bat -Color "AA00FF" -Brightness 30

# Iniciar arco-íris com o Windows, sem janela
.\hs80-rgb.bat -InstallStartup -Effect Rainbow -Brightness 30 -Period 10

# Remover o atalho e os arquivos instalados; não para animações já ativas
.\hs80-rgb.bat -UninstallStartup
```

O headset deve ser o modelo USB com fio. Os dois logos são controlados como uma única zona; não há controle individual por lado. A Corsair e seu logotipo pertencem à fabricante. Este projeto independente não é afiliado nem endossado por ela.
