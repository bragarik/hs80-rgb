# HS80 RGB v0.1.0 — prévia para Windows

Controle os LEDs laterais do **Corsair HS80 RGB USB com fio (`1B1C:0A88`)** sem instalar o iCUE. O programa envia os comandos e encerra, sem manter um serviço em execução.

## Download e uso

1. Baixe **`hs80-rgb-v0.1.0.zip`** na seção **Assets** abaixo.
2. Extraia todo o conteúdo do ZIP.
3. Feche o iCUE e outros aplicativos que controlem a iluminação do fone.
4. Execute **`hs80-rgb.bat`** para apagar os LEDs laterais.

Não é necessário instalar Git, Python ou bibliotecas adicionais. Use o PowerShell do Windows 11.

Para escolher uma cor pelo terminal na pasta extraída:

```powershell
.\hs80-rgb.bat -Color "0080FF" -Brightness 50
```

Para apagar a cada login do usuário atual:

```powershell
.\hs80-rgb.bat -InstallStartup
```

Para remover a inicialização automática:

```powershell
.\hs80-rgb.bat -UninstallStartup
```

## Incluído nesta prévia

- Apagar os LEDs laterais com dois cliques.
- Preset padrão apagado: cor preta e brilho 0%, tanto na execução manual quanto ao configurar a inicialização sem argumentos adicionais. Informar uma cor sem brilho continua aplicando essa cor a 100%; valores explícitos de brilho são preservados.
- Escolher uma cor estática hexadecimal e intensidade de 0 a 100%.
- Instalar ou remover a execução única ao entrar no Windows.
- Diagnóstico de interfaces HID e prévia dos comandos sem acessar USB.
- Seleção da coleção HID pelos valores observados no Windows: página `0xFFC5`, uso `0x0001`, saída de 16 bytes e relatório `C8`, distinguindo `Col01` e `Col02` no mesmo fone.
- Comando `-Version`, que identifica esta revisão como `0.1.0+rev.4` sem acessar USB.
- Código-fonte, instruções, testes e licença GPL-3.0-or-later.

## Validação e limites

Apagar os LEDs, escolher uma cor e ajustar o brilho foram confirmados no HS80 USB por um usuário no Windows 11. **A execução automática no login ainda aguarda teste no hardware.** Os testes automatizados validam compilação, parâmetros, pacotes e empacotamento; eles não substituem esse teste físico. Para atualizar uma instalação anterior e salvar o novo padrão de brilho 0%, execute `hs80-rgb.bat -InstallStartup` novamente a partir do pacote atualizado.

Esta versão atende somente ao HS80 **USB com fio**, identificador `1B1C:0A88`. Não cobre modelos Wireless ou MAX. A intensidade é calculada nos canais RGB. A execução manual não altera a preferência salva para o próximo login.

Depois de reconectar o fone ou perder a alimentação USB, pode ser necessário executar o programa novamente. O projeto não oferece ajuste separado do indicador do microfone; confira se o LED vermelho continua indicando o estado de mudo normalmente.

O arquivo **`hs80-rgb-v0.1.0.zip.sha256`** permite conferir a integridade do download. Consulte o README para mais exemplos e diagnóstico.
